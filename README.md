Одностраничный сайт-портфолио: вёрстка, SEO-разработка и продвижение.
Чистый HTML, CSS и ванильный JS — без сборки, без фреймворков, без зависимостей.

- **Демо:** https://ruslangit1235.github.io/portfolio/
- **Репозиторий:** https://github.com/Ruslangit1235/portfolio

## Что умеет интерфейс

- **Тёмная и светлая темы.** Переключатель в шапке, выбор запоминается в `localStorage`,
  первый заход берёт системную настройку.
- **Живой стенд в герое.** Внутри — настоящий `iframe` с демо «Ваша Кухня», а не картинка.
  Ширину меняют кнопки 360/768/1280, тяга за правый край или стрелки на самой ручке:
  медиазапросы внутри сайта срабатывают по-настоящему.
- **Кейсы в диалоге.** Клик по карточке открывает `<dialog>` с описанием, цифрами, тегами
  и тем же живым стендом — с переключением 390/768/1280.
- **Фильтр работ** по категориям: сайты, интерфейсы, инструменты, письмо.
- **Палитра команд.** ⌘K / Ctrl+K или `/` — поиск по разделам и кейсам,
  стрелки и Enter работают.
- **Копирование контактов** одним кликом, часы по МСК, прогресс чтения, активный пункт меню,
  появление блоков по скроллу.
- **Доступность:** клавиатурная навигация, видимый фокус, `aria-*` на переключателях,
  `prefers-reduced-motion` отключает анимации, без JS контент остаётся видимым.

## Как добавить кейс

1. Положить демо в `works/<имя>/`, превью — в `assets/works/<имя>.jpg` (1280×800).
2. Скопировать любую `<article class="work">` в секции `#works` и заполнить `data-*`:
   `data-title`, `data-kind`, `data-desc`, `data-tags` (через запятую),
   `data-stats` (пары `Ключ:значение` через `|`), `data-demo`, `data-code` (необязательно).
3. Выставить `data-cat`: `site` · `app` · `tool` · `mail`. Кейс сразу появится в фильтре и в ⌘K.
4. Добавить адрес в `sitemap.xml`.

Счётчик в кнопке «все 8» правится там же, в разметке фильтров.

## Локальный просмотр

Можно открыть `index.html` двойным кликом: демо-стенды работают и по `file://`,
все ссылки внутри них ведут на конкретные `index.html`, а не на папки.

Если нужен сервер — как на хостинге:

```bash
cd portfolio
python3 -m http.server 8000
# http://127.0.0.1:8000/
```

## Публикация на GitHub Pages

Ветка `main`, папка `/ (root)`, обновление — обычный `git push`.
Pages пересобирается минуту-две; первый деплой после пуша стоит проверить
в Actions → pages build and deployment.

Файл `.nojekyll` лежит в корне — без него Pages не отдаст `works/kuhnya/_astro/`
(Jekyll игнорирует каталоги с подчёркиванием), и демо кухонь останется без стилей и картинок.

```bash
cd portfolio
git add -A && git commit -m "что поменялось" && git push
```

Папка `.v1/` — резервная копия прежней версии сайта. Лежит локально, в `.gitignore`.
